# 公众号导出

Ink 的第一个插件。把当前文档排成公众号文章，样式全部内联，粘贴到公众号编辑器里就是排好的样子。只在本机处理，不调用微信接口。

## 命令

| 命令 | 快捷键 | 作用 |
|---|---|---|
| 公众号导出：复制为公众号文章 | `⌥⇧⌘C` | 按 HTML 格式放进剪贴板，到公众号编辑器里粘贴 |
| 公众号导出：导出公众号预览网页… | | 存成一个网页，用浏览器打开能预览，点「复制正文」再去粘贴 |

两条命令都会检查要注意的地方，提示显示在状态栏：

- 本地图片：公众号读不到。先用「上传文档中的本地图片」传到图床，或在公众号编辑器里重新插入。
- 公式（MathML）：公众号多半显示不出来，建议截图换成图片。
- Mermaid 图表（SVG）：粘贴后确认效果，不行就截图。

## 做了哪些改写

- 每个标签补上内联样式（标题、段落、引用、列表、表格、代码、图片等），主题色默认 `#0F4C81`。
- `div` 换成 `section`，去掉 `class`、`id`、`data-*`。
- 代码块里的空格和换行换成 `&nbsp;` 和 `<br/>`，公众号不会压掉缩进。
- 外链：公众号正文不能放外链，链接文字留下、加 `[1]` 这样的编号，网址列在文末「引用链接」。公众号自己的文章链接（`mp.weixin.qq.com`）保留。
- 任务列表的勾选框换成 ☑ / ☐，脚注一行一条放在文末，宽表格可以横向滑动，图表按正文宽度缩放。

## 安装

```sh
cp -R examples/wechat-export "$HOME/Library/Application Support/Ink/notes/Ink/plugins/"
ink plugin enable wechat-export
```

重新打开 Ink，在命令面板（`⇧⌘P`）里搜「公众号」。

主题色在插件文件夹的 `data.json` 里改：`{ "color": "#07C160" }`。

不开窗口试一下：

```sh
ink plugin run examples/wechat-export copy 文章.md > 公众号.html
ink plugin run examples/wechat-export export 文章.md -o 预览.html
```
